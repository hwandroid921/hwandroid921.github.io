문제 해결

번호판 오인식 결과가 운행 기록에 저장되는 문제
문제
FastAPI 번호판 인식 기능을 Spring Boot 서비스와 연동하는 과정에서, 촬영 각도·거리·조명에 따라 YOLO가 번호판 영역을 찾지 못하거나 일부만 탐지했습니다. 영역이 정상적으로 추출되어도 OCR이 비슷한 숫자와 문자를 잘못 읽는 경우가 있었습니다.
판단
인식 결과를 그대로 차량번호로 사용하면, 잘못된 결과가 데이터베이스에 저장되어 다른 차량의 운행 기록과 연결될 수 있다고 판단했습니다.
해결
객체 탐지 성공 여부와 문자 인식 결과를 구분해 처리했습니다. OCR 결과가 없거나 번호판 형식에 맞지 않으면 정상 데이터로 확정하지 않도록 예외 흐름을 구성하고, 신뢰도가 낮은 결과는 사용자가 확인하거나 다시 촬영할 수 있도록 설계했습니다.
배운 점
AI 기능을 서비스에 적용할 때는 모델의 결과를 정답으로 가정하지 않고, 신뢰도 기준과 데이터 형식 검증, 사용자 확인과 실패 처리 구조를 함께 두어야 한다는 점을 배웠습니다.
