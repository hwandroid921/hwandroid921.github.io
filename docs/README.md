# 취업 준비 문서

React 전환 학습 자료는 [학습 폴더](learning/README.md)에 있습니다.

백업 원본에서 복원했으며 원본 파일명과 하위 폴더 구조를 유지했습니다.

- 루트: 이력서, 자기소개서, 업무자질요약 양식, 작성 예시 및 프로젝트 자료
- `MBC/`, `국취제/`: 기관별 이력서
- `job-application/`: 지원 직무별 이력서 양식, 자기소개서 및 지원 점검표
- `review/images/`: 기존 이력서 PDF 검토 이미지

DOCX, PDF, ODG 및 이미지의 파일 구조를 확인했습니다. 구형 DOC는 파일 헤더만 확인했으며 문서 레이아웃이나 내용의 정확성을 보증하지 않습니다.
기존 검수 기록은 작업 폴더 밖의 백업에 보관되어 있습니다.
