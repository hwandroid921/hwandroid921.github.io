# 지원 전 점검표

## 제출 서류

- [ ] 백엔드 또는 풀스택 이력서를 선택했다.
- [ ] 회사명과 지원 직무가 문서 제목에 들어 있다.
- [ ] 회사가 요구하는 자기소개서 문항을 모두 작성했다.
- [ ] 프로젝트 기술서 또는 포트폴리오 링크를 첨부했다.
- [ ] 필요한 경우 수료증·자격증·성적증명서를 준비했다.
- [ ] 모든 문서를 PDF로 변환하고 열어 보았다.

## 이력서

- [ ] 1~2페이지 이내다.
- [ ] 전화번호와 이메일이 정확하다.
- [ ] GitHub, 포트폴리오, 블로그 링크가 열린다.
- [ ] 근무 가능 지역을 서울·인천·경기 및 이전 협의 가능으로 적었다.
- [ ] 프로젝트별 기간, 인원, 본인 역할을 표시했다.
- [ ] 팀 전체 구현과 본인 구현을 구분했다.
- [ ] 측정하지 않은 수치가 없다.
- [ ] `[확인 필요]`, `[측정 후 입력]` 표시를 모두 제거했다.
- [ ] 실제로 설명할 수 없는 기술을 제거했다.
- [ ] 자격증의 정식 명칭, 발급기관, 취득일을 확인했다.

## 자기소개서

- [ ] 첫 문장에 문항의 결론이 있다.
- [ ] 회사명과 직무명이 정확하다.
- [ ] 공고의 주요업무 또는 자격요건과 경험을 연결했다.
- [ ] 상황, 행동, 결과가 구분된다.
- [ ] 추상적인 성격 설명을 프로젝트 사례로 증명했다.
- [ ] 동일한 내용을 여러 문항에서 반복하지 않는다.
- [ ] 대학 중퇴 설명은 필요한 경우에만 사용했다.
- [ ] 입사 후 포부가 회사와 관계없는 장기 목표로 끝나지 않는다.

## 공고 확인

- [ ] 마감일과 접수 방법을 다시 확인했다.
- [ ] 학력과 경력 조건을 확인했다.
- [ ] 정규직·인턴·계약직 여부를 확인했다.
- [ ] 근무지와 출퇴근 시간을 확인했다.
- [ ] 필수 제출 파일과 파일 크기 제한을 확인했다.
- [ ] 코딩테스트, 과제, 면접 절차를 확인했다.

## 제출 파일명

```text
유환희_백엔드개발자_이력서.pdf
유환희_풀스택개발자_이력서.pdf
유환희_자기소개서_[회사명].pdf
유환희_프로젝트기술서.pdf
유환희_교육수료증.pdf
유환희_자격증.pdf
```

## 개인정보

- [ ] 공개 저장소에 전화번호, 생년월일, 상세 주소를 올리지 않았다.
- [ ] PDF 메타데이터에 불필요한 개인정보가 없는지 확인했다.
- [ ] API 키, 세션, 비밀번호가 저장소와 첨부파일에 없는지 확인했다.
