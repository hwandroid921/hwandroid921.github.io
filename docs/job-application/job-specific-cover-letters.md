# 공고별 자기소개서 문항

아래 문항은 공고에 공식 입력 문항이 없는 경우에도 자유양식 자기소개서와 면접 준비에 사용하는 맞춤 문항이다. 지원 전 공고 원문에서 마감 여부와 자격요건을 다시 확인한다.

## 공통 자유양식

회사 자체 문항이 없으면 다음 세 문항으로 구성한다.

### 1. 지원동기 및 직무 적합성 — 500~600자

```text
제가 [회사명]의 [직무명]에 지원한 이유는
[공고의 주요업무]가 프로젝트에서 경험한
[관련 경험]과 연결되기 때문입니다.

[프로젝트명]에서 [역할]을 맡아
[기술과 기능]을 구현했습니다.
이 과정에서 [문제]를 경험했고,
[행동]을 통해 해결했습니다.

이 경험을 바탕으로 입사 후
[공고 업무]에 기여하고 싶습니다.
```

### 2. 대표 프로젝트와 문제 해결 — 600~700자

```text
가장 대표적인 프로젝트는 [프로젝트명]입니다.
이 프로젝트는 [서비스 설명]이며,
저는 [인원·역할]을 담당했습니다.

개발 과정에서 [구체적인 문제]가 발생했습니다.
[원인 확인 방법]을 통해 원인을 분석했고,
[구체적인 수정]을 적용했습니다.
이후 [테스트 또는 측정]으로 결과를 확인했습니다.

이 경험을 통해 [직무와 관련된 교훈]을 배웠습니다.
```

### 3. 협업 및 입사 후 계획 — 400~500자

```text
저는 협업에서 역할의 경계뿐 아니라
기능의 완료 기준을 공유하는 것이 중요하다고 생각합니다.

[프로젝트명]에서 [협업 문제]가 발생했을 때
[문서화·회의·GitHub·Notion]을 이용해 해결했습니다.

입사 후에는 회사의 코드와 업무 방식을 먼저 익히고,
작은 기능과 버그 수정부터 테스트와 기록을 남기며
안정적으로 기여하겠습니다.
```

## 엑심베이 — 개발자 인턴

공고: https://www.jobkorea.co.kr/Recruit/GI_Read/49536854

### 준비 문항

1. 엑심베이 개발자 인턴에 지원한 이유는 무엇인가?
2. 결제 시스템에서 중요하다고 생각하는 품질은 무엇인가?
3. 중복 요청이나 실패 상태를 처리한 경험이 있는가?
4. 인턴 기간에 배우고 기여하고 싶은 것은 무엇인가?

### 연결 경험

- ReadMe의 주문·결제 화면과 API 연동
- LogMile의 인증·인가와 예외 처리
- 중복 클릭 방지 및 사용자 상태 처리

### 지원동기 도입부

```text
쇼핑몰 프로젝트에서 주문과 결제 흐름을 구현하면서
결제 기능은 성공 화면을 표시하는 것뿐 아니라
중복 요청 방지, 실패 상태 처리, 데이터 일관성이
중요하다는 점에 관심을 갖게 되었습니다.
```

ReadMe에서는 프론트엔드 결제 흐름을 담당했다. 서버 결제 전체를 구현한 것처럼 표현하지 않는다.

## 마드라스체크 — SaaS 개발자

공고: https://www.wanted.co.kr/wd/373073

### 준비 문항

1. 프론트엔드와 백엔드를 모두 경험한 것이 SaaS 개발에 어떤 도움이 되는가?
2. 요구사항을 API와 화면으로 구체화한 경험은 무엇인가?
3. 운영 중인 서비스의 오류를 발견하면 어떤 순서로 접근할 것인가?
4. jQuery와 Node.js 등 익숙하지 않은 기술에 어떻게 적응할 것인가?
5. 협업 도구로 변경사항을 공유한 경험은 무엇인가?

### 연결 경험

- ReadMe: Vue 프론트엔드와 REST API 연동
- LogMile: Spring Boot REST API와 PostgreSQL
- TokenMonitor: 개인 제품의 기획부터 배포까지

### 핵심 문장

```text
프로젝트마다 프론트엔드 또는 백엔드 역할을 맡으면서
한쪽 기능의 변경이 다른 영역에 어떤 영향을 주는지 경험했습니다.
이를 바탕으로 화면 요구사항을 API와 데이터 구조까지
연결해 이해할 수 있습니다.
```

### 부족한 기술 설명

```text
Node.js를 주 백엔드로 사용한 경험은 없지만,
TypeScript와 Electron 프로젝트 경험이 있으며
Spring Boot로 REST API를 설계했습니다.
이 경험을 바탕으로 런타임과 프레임워크의 차이를 학습하며
빠르게 적응하겠습니다.
```

## 평행 — 웹 백엔드·Windows 응용프로그램

공고: https://www.jobkorea.co.kr/Recruit/GI_Read/49492437

### 준비 문항

1. 웹 서비스와 Windows 애플리케이션을 개발한 경험을 설명하라.
2. 신입이지만 경력 1년 이상 공고에 지원한 이유는 무엇인가?
3. C# 등 익숙하지 않은 기술을 맡으면 어떻게 학습할 것인가?
4. 사용자 PC에서 발생하는 문제를 어떻게 진단할 것인가?

### 연결 경험

- TokenMonitor: Electron 기반 Windows 애플리케이션
- LogMile: Spring Boot 웹 백엔드

### 경력 부족 설명

```text
정식 실무 경력은 없지만 팀 프로젝트에서 Spring Boot 백엔드를 담당했고,
개인적으로 Electron 기반 Windows 애플리케이션을
기획부터 패키징까지 진행했습니다.
공고의 두 업무 영역을 모두 프로젝트에서 경험했다는 점을 바탕으로
도전하게 되었습니다.
```

### 준비 문항

1. 교육 서비스에서 안정적인 API가 중요한 이유는 무엇인가?
2. RDBMS를 설계하고 데이터를 조회한 경험을 설명하라.
3. 사용자 증가로 조회가 느려지면 어떻게 분석할 것인가?
4. 요구 경력보다 부족하지만 지원한 이유는 무엇인가?
5. 교육 도메인에 관심을 가진 이유는 무엇인가?

### 연결 경험

- LogMile의 REST API, JPA, PostgreSQL
- ReadMe의 사용자·관리자·결제 흐름
- 인덱스와 성능 테스트를 완료한 후 해당 결과

### 경험 부족 설명

```text
아직 대규모 트래픽을 운영한 경험은 없습니다.
현재 LogMile의 주행 기록 조회 기능에 테스트 데이터를 구성하고
실행 계획과 인덱스 적용 전후를 측정하며 보완하고 있습니다.
```

완료하지 않은 개선을 완료한 경험처럼 작성하지 않는다.
