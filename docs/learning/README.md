# 포트폴리오 개발 학습

1. [Vue 경험으로 배우는 React 포트폴리오 전환](react-portfolio-guide.md): 기존 화면을 단계별로 옮기며 실행 흐름, JSX, 컴포넌트, props, 타입과 상태 관리를 익힙니다.
2. [React 포트폴리오 Cloudflare 배포 실습](cloudflare-deployment-guide.md): React 전환 후 빌드 결과를 Workers Static Assets에 배포하고, 화면 검증·재배포·이전 버전 복원을 배웁니다.

예제는 학습용이며 React 앱 전환과 Cloudflare 배포는 아직 진행하지 않았습니다. 실습 파일은 `prototype/`, 학습 문서는 이 폴더에 둡니다. 배포 실습은 React 전환 안내서의 1~6단계를 마친 뒤 시작합니다.
