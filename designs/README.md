# 포트폴리오 HTML 시안

index.html을 브라우저로 열면 7개 시안을 비교할 수 있습니다. 각 시안은 별도 HTML이며 공통 style.css, ui.js, assets의 로컬 Pretendard 폰트를 사용합니다. 서버나 빌드 과정 없이 파일로도 열립니다.

본문: max-width 1280px, margin-inline auto. 일반 화면 최소 좌우 32px, 720px 이하에서는 최소 좌우 20px. 스크롤바를 제외한 가용 너비 기준입니다. 중앙 영역의 안쪽 여백은 데스크톱 48px, 태블릿 32px, 모바일 20px입니다. 1280px 안쪽 배경은 `#F6F8FC`, 양옆 바깥 여백은 연한 블루 `#EBF3FF`입니다.

내용은 HTML의 대괄호 항목을 수정하세요. PDF·GitHub·이메일·글 링크는 실제 자료가 없어 안내창으로 처리했습니다. 실제 주소를 연결할 때 data-empty 속성을 제거하고 href를 지정하세요. PDF 버튼은 파일을 가리키는 링크로 바꾸세요.

비교 페이지의 미리보기 이미지는 ../drafts/unified-v2의 원본을 참조합니다. 폴더를 옮길 때 이 경로도 함께 유지하세요. 개별 HTML은 이미지에 의존하지 않습니다.

프로젝트마다 회색 대표 이미지 영역 1개씩, 총 2개씩 배치했습니다. 실제 이미지를 넣을 때 각 `<figure class="project-media">` 안의 `<div class="media-empty">...</div>`를 `<img src="assets/파일명.webp" alt="프로젝트 화면 설명">`으로 교체하세요. 이미지 비율은 기본 16:10이며 화면 너비에 맞게 표시됩니다. 7개 시안 모두 프로젝트가 자기소개 다음에 나오도록 배치했습니다.

공통 컬러(v3): 중앙 배경 `#F6F8FC`, 양옆 배경 `#EBF3FF`, 제목 `#172B46`, 본문 `#5F6F83`, 구분선 `#DCE5F0`, 링크·버튼 `#315A99`, 프로젝트 이미지 자리 `#EAF0F7`. 7개 화면은 한 CSS를 공유하므로 색상을 한 번에 조정할 수 있습니다.

03 프로젝트 문서형: 왼쪽은 경력·소개·연락 링크가 있는 개인 정보 사이드바, 오른쪽은 페이지 목차입니다. 연락처는 실제 정보를 넣기 전까지 빈 항목 안내를 표시합니다.

07 사이드바 + 스토리형: 02의 왼쪽 프로필·목차·연락처 사이드바와 01의 오른쪽 프로젝트 이미지/설명 교차 배치, 경력·기술 2열, 기술 기록·교육 2열을 결합했습니다. 본문 최대 너비 1280px과 공통 색상·Pretendard를 그대로 사용합니다.
